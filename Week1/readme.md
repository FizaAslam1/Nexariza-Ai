## 📌 Project Overview

Predict wine quality (Good/Bad) using chemical properties.

- **Data:** 1,599 red wines, 11 features
- **Target:** Quality ≥ 7 = Good, < 7 = Bad
- **Goal:** Classify wine quality before bottling

---

## 📊 Results

| Model | Accuracy |
|-------|----------|
| **Ensemble (Best)** | **94.2%** |
| Random Forest | 93.8% |
| XGBoost | 93.1% |

### Top Features
1. **Alcohol** — 34.1% importance
2. **Sulphates** — 10.5%
